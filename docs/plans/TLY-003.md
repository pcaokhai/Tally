# TLY-003 — Contract pipeline and code generation

**Spec:** `docs/06-user-stories.md` → "TLY-003 Contract pipeline and code generation" (Lane PLAT, 5 pts, depends TLY-001, traces NFR-MNT-04, ADR-009).
**Supporting:** `docs/04-api-contract.md` §8, `docs/07-delivery-plan.md` Sprint 0, root `CLAUDE.md` §3/§5/§6.
**Branch:** `feat/TLY-003-contract-pipeline`

## Acceptance criteria (verbatim from docs/06)

1. `make contracts` runs the three generators, Spectral lint (0 errors), oasdiff against `main` (breaking change fails unless the PR has label `breaking-approved`), JSON Schema compile and the webhook vector self-check.
2. `make gen` produces Spring interfaces for core, Go types + sqlc models for workers, and openapi-typescript clients + MSW handlers for web and ops-web; generated folders are marked read-only in CODEOWNERS.
3. Changing a response field in `scripts/gen_openapi.py` and running `make gen` produces a compile error in core until the handler is updated (demonstrated in the PR).
4. CI fails if `make contracts` leaves a diff in `contracts/` (generated files must be committed).

## Starting state (verified)

- `make contracts` already runs the three generators; `gen_events.py` already does JSON Schema compile (`Draft202012Validator.check_schema` + fixture validation) and `gen_webhook_vectors.py` already self-verifies its five vectors. **Missing: Spectral, oasdiff.**
- `make gen` calls `./gradlew openApiGenerate` (task does not exist), `go generate ./...` (no directives), `pnpm gen` in web + ops-web (both `echo … && exit 0`).
- `.github/CODEOWNERS` already reserves the four generated paths: `/core/build/generated/`, `/workers/internal/events/`, `/web/lib/api/generated/`, `/ops-web/lib/api/generated/`. **Generation must target exactly these paths.**
- `.github/workflows/ci.yml` has a `contracts` job running `make contracts` on python 3.12 with `pyyaml jsonschema`. It needs node (Spectral), go (oasdiff) and `fetch-depth: 0` (oasdiff baseline).
- Spec size: 78 tenant operations, 42 operator operations, 7 event schemas, 5 webhook vectors.
- Toolchain present: Java 25 + Gradle 9.4.1, Go 1.27.1, Node 24 + pnpm 9.14.2, Python 3.14, `sqlc`, network access to npm/Maven/proxy.golang.org. `oasdiff` installed to `~/go/bin` during pre-flight; the pipeline must install it itself when absent.

## Global Constraints

- **Never hand-edit anything under `contracts/`.** Change `scripts/gen_*.py` and re-run `make contracts`. Never hand-edit generated code under the four CODEOWNERS generated paths.
- **Lane ownership.** Touch only: `scripts/`, `Makefile` (`contracts` and `gen` targets only — never `up`/`down`/`seed`, TLY-002 owns those concurrently), `contracts/` (regenerated output only), `.github/workflows/ci.yml` (`contracts` job only), `.github/CODEOWNERS`, `.spectral.yaml`, `.gitignore`, and the codegen wiring inside `core/`, `workers/`, `web/`, `ops-web/`. - Money stays integer minor units — never introduce a float/BigDecimal representation in any generated mapping config.
- Commit generated code for workers/web/ops-web (CODEOWNERS lists those paths); core's generated sources land under `core/build/generated/` which is already git-ignored by `core/.gitignore`.
- Conventional Commits, scope `plat`, story id in the subject: `feat(plat): … (TLY-003)`.

## Task 1 — Spectral lint in `make contracts`

**Files:** `.spectral.yaml` (new), `scripts/gen_openapi.py`, `Makefile`, `contracts/openapi.yaml` + `contracts/ops-openapi.yaml` (regenerated only).

1. Verify the failing state first: `npx -y @stoplight/spectral-cli@6.16.3 lint --ruleset .spectral.yaml contracts/*.yaml` — `.spectral.yaml` does not exist, so the command fails.
2. Add `.spectral.yaml`:
   - `extends: [[spectral:oas, all]]`
   - `rules: { oas3-unused-component: off }` with a comment: both specs are built from one shared `components.schemas` map in `gen_openapi.py` (`{**S, **schemas}`), so every spec carries schemas the other one uses — the rule is a structural false positive here.
   - one project rule `tally-operation-id-required`: every operation must have `operationId`, severity `error` (the generators rely on it for every downstream codegen step).
3. Fix the two real findings in `scripts/gen_openapi.py`'s `build()` so the generated specs lint clean (both feed codegen quality — `tags` names the generated Java API interfaces):
   - `info.contact` → `{"name": "Tally platform team", "url": "https://github.com/pcaokhai/tally"}`
   - top-level `tags:` list derived from the distinct `tag` column of the row tables, each `{"name": ..., "description": ...}` — every `operation-tag-defined` warning must disappear.
4. Wire into `Makefile`'s `contracts` target, after the three generators and before the `git diff --quiet` check:
   `npx -y @stoplight/spectral-cli@6.16.3 lint --ruleset .spectral.yaml --fail-severity=warn contracts/openapi.yaml contracts/ops-openapi.yaml`
   (`--fail-severity=warn` is strictly stronger than the AC's "0 errors" and is achievable because of step 3.)

**Verify:** `make contracts` prints `No results with a severity of 'warn' or higher found!` and exits 0; run it twice and `git status --short` is clean the second time. ## Task 2 — oasdiff breaking-change gate + AC4 diff gate

**Files:** `scripts/oasdiff-gate.sh` (new, executable), `Makefile`, `.github/workflows/ci.yml` (`contracts` job only), `.gitignore`.

1. `scripts/oasdiff-gate.sh`:
   - Pin `OASDIFF_VERSION` (use the version resolved during pre-flight; `go install github.com/oasdiff/oasdiff@v<VERSION>` into `GOBIN=<repo-root>/.bin` when `.bin/oasdiff` is absent and `oasdiff` is not already on `PATH`). Add `.bin/` to `.gitignore`.
   - Baseline: first of `origin/main`, `main` that `git rev-parse --verify` resolves; if neither exists (shallow clone / no main), print a clear skip line and exit 0.
   - For each of `contracts/openapi.yaml`, `contracts/ops-openapi.yaml`: write the baseline copy to a temp file via `git show <base>:<path>` (skip the file if it does not exist at the baseline — new spec, nothing to break), then run `oasdiff breaking <base-tmp> <current> --fail-on ERR`.
   - Escape hatch: when `BREAKING_APPROVED=1` (or `true`), still print the breaking report but exit 0, and echo that the `breaking-approved` label was honoured.
   - `set -euo pipefail`; clean up temp files with a trap.
2. Wire into `Makefile`'s `contracts` target after Spectral: `./scripts/oasdiff-gate.sh`.
3. `.github/workflows/ci.yml` `contracts` job:
   - `actions/checkout@v4` with `fetch-depth: 0`
   - add `actions/setup-node@v4` (node from `.tool-versions`) and `actions/setup-go@v5` (go from `.tool-versions`)
   - pass the label through: `env: BREAKING_APPROVED: ${{ contains(github.event.pull_request.labels.*.name, 'breaking-approved') && '1' || '0' }}`
   - keep `make contracts` as the single command — the `git diff --quiet -- contracts/` line already in the target is AC4's gate.

**Verify:**
- `make contracts` green with no breaking change.
- AC1 breaking gate: change a response field name in `scripts/gen_openapi.py`, run `make contracts`, paste the non-zero oasdiff failure; re-run with `BREAKING_APPROVED=1 make contracts` and paste it passing the gate; revert the generator change and re-run clean.
