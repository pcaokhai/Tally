# Implementation plans

One file per story, written by the **writing-plans** skill before any code: `docs/plans/<ID>.md` (e.g. `TLY-505.md`).

Each plan contains:
1. Understanding — one paragraph citing the doc sections and AC ids.
2. Rulings — any conflict between documents and how it was resolved (for tech-lead review).
3. Reserved resources — migration numbers, topic/flag names.
4. Tasks — 2–5 minutes each: exact files, the failing test to write first (named with the AC id), the implementation step, the verification command.
5. Verification — the commands whose real output will be pasted before completion.

Plans are kept after merge as the learning record (risk R-02).
