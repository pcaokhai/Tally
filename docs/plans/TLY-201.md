# TLY-201 — Money value object

Track A (pure domain value type, no I/O). Lightweight path per CLAUDE.md §4a.

`kernel/money/Money` already exists (from TLY-004 scaffold) with `plus`/`minus` and a
plain `IllegalArgumentException` on currency mismatch. This story extends it to full AC.

## Tasks

1. `CurrencyMismatch` exception (extends `IllegalArgumentException` — keeps existing
   TLY-004 tests passing while giving AC2 a named type) — RED test first.
2. `Money.times(long)`, `negate()`, `isZero()` using `Math.*Exact` — RED test first.
3. `Money.allocate(long... ratios)` — largest-remainder split, sum of parts == whole.
   Property test: 10,000 random (amount, ratios) pairs, plain JUnit loop (no new
   dependency — jqwik isn't in the build and this doesn't need generative shrinking).
4. `MoneyModule` (Jackson 3 `SimpleModule`) serializing `{amount, currency}` (lowercase
   field names — record fields are already `minor`/`currency`, so the wire name `amount`
   needs an explicit serializer, not `@JsonProperty` alone since `minor` must stay the
   record's internal name). Deserializer rejects a non-integral JSON number.
