# TLY-001 Monorepo scaffold, Makefile and CI skeleton — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `make lint test` pass on a clean clone with only Docker, JDK 25, Go 1.27 and pnpm installed, and wire GitHub Actions to run lint/test/contracts/gitleaks per changed lane, enforce a story id in every PR title, and pin toolchain versions in one file.

**Architecture:** Root scaffolding only — no feature code. The Makefile, CODEOWNERS and PR template already exist (committed in the initial scaffold commit) and stay mostly as-is; this story adds the pieces docs/06 TLY-001 requires that are still missing: `.tool-versions`, empty-but-green per-lane check targets (`core`, `workers`, `web`, `ops-web` each get minimal buildable skeletons that satisfy `lint`/`test`), and `.github/workflows/ci.yml` with path-filtered jobs plus a `pr-title` job.

**Tech Stack:** GNU Make, GitHub Actions, asdf-style `.tool-versions`, Gradle (Java 25 toolchain), Go 1.27 modules, pnpm workspaces (Node LTS).

**Spec:** docs/06-user-stories.md (TLY-001, lines ~1–25), docs/07-delivery-plan.md §7–9, core/CLAUDE.md, workers/CLAUDE.md, web/CLAUDE.md, ops-web/CLAUDE.md.

## Global Constraints

- JDK 25, Go 1.27, Node LTS, pnpm — pinned in `.tool-versions`, CI must read versions from that file, not hardcode them (AC4).
- `make lint test` must exit 0 on a clean clone with only Docker, JDK 25, Go 1.27, pnpm installed (AC1) — no network calls to unpinned registries beyond normal package installs.
- CI runs lint, test, contracts, gitleaks per changed lane using path filters, and posts results on the PR (AC2).
- A PR title without a `TLY-nnn` story id fails the `pr-title` check (AC3).
- `make docs-check` (already wired to `scripts/validate_pack.py`) must stay green and is part of CI (AC5).
- PR size ≤ 400 changed lines excluding generated code (docs/07 §8) — this story is scaffolding only, expect it to run over on file count but stay near that budget in real code.
- No secrets, tokens or real credentials anywhere, including in workflow YAML or fixtures (docs/10 §0.6, root CLAUDE.md §9).

### Task 5: GitHub Actions CI — path-filtered lane jobs, pr-title check, gitleaks, docs-check

**Files:**
- Create: `.github/workflows/ci.yml`
- Create: `.github/workflows/pr-title.yml`

**Interfaces:**
- Consumes: `.tool-versions` (parsed with `grep`/`cut` per job), the `make lint`/`make test`/`make contracts`/`make docs-check` targets already defined in `Makefile`, `scripts/validate_pack.py` (already present).
- Produces: PR check names `plat`, `core`, `work`, `web`, `opsw`, `gitleaks`, `pr-title` that TLY-002/003 and every later story's PR relies on turning green.

- [ ] **Step 1: Write `.github/workflows/pr-title.yml`**

```yaml
name: pr-title

on:
  pull_request:
    types: [opened, edited, synchronize]

jobs:
  pr-title:
    runs-on: ubuntu-latest
    steps:
      - name: Require a TLY-nnn story id in the PR title
        env:
          TITLE: ${{ github.event.pull_request.title }}
        run: |
          echo "$TITLE" | grep -Eq '(^|[^A-Z0-9])TLY-[0-9]{3,}([^0-9]|$)' || {
            echo "PR title must contain a story id like TLY-001. Got: $TITLE"
            exit 1
          }
```

- [ ] **Step 2: Write `.github/workflows/ci.yml`**

```yaml
name: ci

on:
  pull_request:
  push:
    branches: [main]

jobs:
  changes:
    runs-on: ubuntu-latest
    outputs:
      plat: ${{ steps.filter.outputs.plat }}
      core: ${{ steps.filter.outputs.core }}
      work: ${{ steps.filter.outputs.work }}
      web: ${{ steps.filter.outputs.web }}
      opsw: ${{ steps.filter.outputs.opsw }}
      contracts: ${{ steps.filter.outputs.contracts }}
    steps:
      - uses: actions/checkout@v4
      - uses: dorny/paths-filter@v3
        id: filter
        with:
          filters: |
            plat:
              - 'Makefile'
              - '.tool-versions'
              - 'scripts/**'
              - 'deploy/**'
              - '.github/**'
            core:
              - 'core/**'
            work:
              - 'workers/**'
            web:
              - 'web/**'
              - 'pnpm-workspace.yaml'
              - 'package.json'
            opsw:
              - 'ops-web/**'
              - 'pnpm-workspace.yaml'
              - 'package.json'
            contracts:
              - 'contracts/**'
              - 'scripts/gen_openapi.py'
              - 'scripts/gen_events.py'
              - 'scripts/gen_webhook_vectors.py'

  core:
    needs: changes
    if: needs.changes.outputs.core == 'true'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Read Java version
        id: tv
        run: echo "java=$(grep '^java ' .tool-versions | cut -d' ' -f2 | cut -d. -f1)" >> "$GITHUB_OUTPUT"
      - uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: ${{ steps.tv.outputs.java }}
      - run: cd core && ./gradlew spotlessCheck archTest
      - run: cd core && ./gradlew test integrationTest

  work:
    needs: changes
    if: needs.changes.outputs.work == 'true'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Read Go version
        id: tv
        run: echo "go=$(grep '^golang ' .tool-versions | cut -d' ' -f2)" >> "$GITHUB_OUTPUT"
      - uses: actions/setup-go@v5
        with:
          go-version: ${{ steps.tv.outputs.go }}
      - uses: golangci/golangci-lint-action@v6
        with:
          working-directory: workers
      - run: cd workers && go build ./... && go test -race ./...

  web:
    needs: changes
    if: needs.changes.outputs.web == 'true'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Read Node/pnpm versions
        id: tv
        run: |
          echo "node=$(grep '^nodejs ' .tool-versions | cut -d' ' -f2)" >> "$GITHUB_OUTPUT"
          echo "pnpm=$(grep '^pnpm ' .tool-versions | cut -d' ' -f2)" >> "$GITHUB_OUTPUT"
      - uses: pnpm/action-setup@v4
        with:
          version: ${{ steps.tv.outputs.pnpm }}
      - uses: actions/setup-node@v4
        with:
          node-version: ${{ steps.tv.outputs.node }}
          cache: pnpm
      - run: pnpm install --frozen-lockfile
      - run: pnpm --filter web lint && pnpm --filter web typecheck
      - run: pnpm --filter web test

  opsw:
    needs: changes
    if: needs.changes.outputs.opsw == 'true'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Read Node/pnpm versions
        id: tv
        run: |
          echo "node=$(grep '^nodejs ' .tool-versions | cut -d' ' -f2)" >> "$GITHUB_OUTPUT"
          echo "pnpm=$(grep '^pnpm ' .tool-versions | cut -d' ' -f2)" >> "$GITHUB_OUTPUT"
      - uses: pnpm/action-setup@v4
        with:
          version: ${{ steps.tv.outputs.pnpm }}
      - uses: actions/setup-node@v4
        with:
          node-version: ${{ steps.tv.outputs.node }}
          cache: pnpm
      - run: pnpm install --frozen-lockfile
      - run: pnpm --filter ops-web lint && pnpm --filter ops-web typecheck
      - run: pnpm --filter ops-web test

  contracts:
    needs: changes
    if: needs.changes.outputs.contracts == 'true' || needs.changes.outputs.plat == 'true'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - run: make contracts

  docs-check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - run: pip install pyyaml
      - run: make docs-check

  gitleaks:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
      - uses: gitleaks/gitleaks-action@v2
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```
