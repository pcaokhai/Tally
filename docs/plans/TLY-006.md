### T2 — Design + motion tokens in one module (AC2)
Files: `web/styles/tokens.css`, `web/lib/tokens.ts`, `web/lib/motion.ts`, `web/.eslintrc.cjs`,
`web/lib/tokens.test.ts`.
- `styles/tokens.css` is the single source: Tailwind v4 `@theme` with every colour, the type
  scale (Geist + Instrument Serif via `next/font`), spacing, radii, durations and easings from
  docs/02 §7.8 (120/200/350 ms; `standard` cubic-bezier(.2,0,0,1), `exit` (.4,0,1,1);
  spring.soft 260/26, spring.snappy 500/30; stagger 35 ms max 8).
- `lib/tokens.ts` / `lib/motion.ts` re-export the same values for TS consumers.
- ESLint `no-restricted-syntax` rules in an `overrides` block for `app/**` + `components/**`:
  ban string literals matching `#[0-9a-fA-F]{3,8}` and `\d+m?s` duration/easing literals.
  `styles/`, `lib/tokens.ts`, `lib/motion.ts` are exempt (they *are* the module).
- RED first: a component file with a raw hex must fail `pnpm lint`.
- Verify: `cd web && pnpm lint && pnpm test`
